# SimShaker icon

An original off-white S with cyan vibration ripples on a charcoal tile. The mark contains no Sony or PlayStation imagery.

`PSVR2SimShaker.png` is the image-generation master with transparent corners. `PSVR2SimShaker.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel versions for Windows. Recreate the ICO with `python scripts/build-icon.py` (requires Pillow); normal app builds use the committed ICO directly.

Created for this project with OpenAI's built-in image-generation tool. The original generation brief is retained in `icon-prompt.txt`. Distributed under the project's GPL-3.0 license.
